Goal:
Build a professional full-stack safety/navigation application where users can:
- Search source and destination like a navigation app.
- Get route(s) from OSRM.
- Analyze hazards near the route using PostgreSQL + PostGIS.
- Calculate safety scores/classifications server-side.
- View safety-aware route information on a Leaflet/OpenStreetMap map.
- Report unsafe areas anonymously.
- Use an SOS feature with browser geolocation and emergency number 112.
- Have an admin panel for hazard moderation.
